# Lessons for KOML

Synthetic evidence validates deterministic mission selection and arithmetic against planted ground truth. It does not validate usefulness to Henry or the quality of operator-supplied lessons.

A mission can have multiple significance triggers. Counting triggers as postmortems would inflate mission counts, so the engine emits one postmortem per mission and keeps trigger counts separately.

Future builds should declare significance rules and provenance before generating fixtures, then corrupt a planted input to prove outputs depend on observations rather than expectations. Root causes need evidence beyond a status or budget breach.
